обрезанный ответ, сбой модели, restart и продолжение истории.

CLI проверен через настоящий локальный HTTP fixture. Дополнительно выполнены
живой CLI-запуск и CLI-продолжение с настоящим MCP и DeepSeek.

## Ошибки, найденные и исправленные при проверке

Предварительные запуски сохранены, чтобы не скрывать диагностику:

- 078f1ab8-a7a5-465f-815b-6704e4c22d18 остановлен старым лимитом 16 шагов
  уже после записи документа. Лимит увеличен до 24; артефакт не потерян.
- d5bf87d2-d535-481f-adb6-4d7842c77df4 остановлен бюджетом контекста
  после ошибок в evidence. Теперь evidence вычисляет сервер по реальным чтениям,
  текст не дублируется в MCP-ответе. Повтор с Qwen завершился успешно.
- 20897d60-0170-4533-99a9-f5fbb95d8acd сохранил нежелательную правку
  исторического раздела README. Такой результат не считается эталоном качества.
  Добавлены предупреждение источника, HISTORY_PROTECTED и отдельный тест.
  Итоговый сценарий исправляет актуальный документ, а не историю.
- Новый тест обнаружил отличие ASCII-регистра от Unicode-регистра
  в русском маркере истории; распознавание исправлено.
- На узком экране длинные пути фрагментов переполняли details;
  добавлен перенос. Diff теперь показывает компактный контекст,
  а скачиваемый полный patch сохраняется без изменений.

Защита истории относится к настроенным явным маркерам, не к произвольной
семантической оценке всех документов.
