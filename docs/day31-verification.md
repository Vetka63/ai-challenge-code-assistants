## Ограничения

IDS_VALID проверяет существование источников, не истинность каждого вывода.
История документации содержит противоречия; модель может перенести
отдельную деталь старой сборки на новую. Источники показываются для проверки,
а не как сертификат правильности. Здесь не реализован семантический judge.

Скорость локального холодного запроса не является сравнительным benchmark.
Изменение игры после проверки может сделать индекс устаревшим — UI
предупредит, но ответит по прежней версии. Для свежих сведений обновите
индекс вручную. Git-ветка игры не переключалась; тесты других веток/путей используют
временный fixture. Мобильный viewport просмотрен; все размеры экранов
и полноценная автоматизация frontend e2e не покрыты.

Проверены исключения Git для .env, runtime-данных, artifacts и node_modules;
секретные шаблоны в публикуемых исходниках не найдены. Raw-ответы остаются
в SQLite/локальных artifacts, не в репозитории.
