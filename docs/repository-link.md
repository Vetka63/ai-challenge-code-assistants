# Связь репозиториев

## Source control

Игра: https://github.com/Vetka63/ai-challenge-game

Ассистент: https://github.com/Vetka63/ai-challenge-code-assistants

Это два независимых репозитория с собственными `main`, коммитами и PR.
Родительская папка `F:/ai-advent-challenge` не становится Git-репозиторием.
Не добавляем соседнюю папку как вложенный `.git`, submodule или копию кода.

## Будущий локальный доступ

В локальной конфигурации ассистента будет выбран разрешённый корень игры.
MCP сообщает Git-ветку/коммит этого корня и читает только разрешённые
файлы. Индексатор использует README/docs и C# с метаданными происхождения.
Точное имя параметра и формат конфигурации пока не реализованы.

Переключение ветки игры не должно переключать ветку ассистента. Ассистент
обнаруживает изменение версии источников и предупреждает об устаревшем
индексе вместо молчаливого использования прежних правил.

## Будущий PR-пайплайн

Workflow находится в репозитории игры. Версионированный runner анализа
поставляется из репозитория ассистента: способ поставки и закрепление
версии согласуем на дне 32. Стартовый GitHub push не создаёт этот pipeline
и не подключает репозитории к работающему RAG/MCP.

Для CI не нужны произвольный доступ к домашнему ПК, автоматический
commit исправлений или право merge. Read/review permissions и платные
вызовы выдаются только в рамках согласованного сценария.
