# Проверка дня 32

Дата: 16 октября 2026. Ветка ai-challenge-day-32 от c728c7a.
Реализован локальный review-домен с GitHub REST-адаптером, worker, SQLite,
RAG по версиям документации/C#, проверкой ответа и Vue UI.
Шаблон Actions хранится в integrations/github/ai-review.yml.

## Автоматические проверки

Офлайн: HelpAgentTest 12, RagAndPolicyTest 8, ReviewTest 12,
ReviewGitHubTest 10, ProjectFilesTest 7, McpProtocolTest 1, Vue/Vitest 10.
Итого 60 пройденных тестов. ReviewLiveTest отдельно выключен по умолчанию.
TypeScript и production build клиента успешны. Backend/Project MCP
скомпилированы Gradle-контейнером; ключи при обычных тестах не используются.

Покрыто: SQLite unique/CAS при конкурентной регистрации и захвате;
сохранность очереди при BUSY; restart INDEXING/ANALYZING;
публикация сохранённого результата без повторной генерации;
точные стороны/строки diff, C# line mapping; чужой repo/автор/fork;
устаревшее задание, неполный patch, ZIP traversal/размер,
запрет произвольного redirect, отсутствие токена на artifact download-хосте;
маркер уже опубликованного комментария; проверка модели по источникам/строкам.
HTTP-адаптер GitHub проверен на fake transport, а не настоящем PR.

ReviewLiveTest выполнен явно с DAY32_LIVE=true. Использовано 3 из 20
разрешённых вызовов deepseek-v4-pro. Embeddings qwen3-embedding:0.6b —
через существующую локальную Ollama. Результаты в игнорируемой папке
artifacts/day32-live, не в Git и не в production-истории ревью.

   ссылка S2. API usage 1028/294.

   ARCHITECTURE, строка 2, ссылка S2. API usage 1056/336.

   API usage 1046/96.

Все результаты REPORT_READY с сохранённым generation и валидными ссылками.
Это проверка реальной модели в нашем use case, но не настоящие игровые PR
