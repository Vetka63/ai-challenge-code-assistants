# Интерфейс помощника разработчика

Vue/TypeScript, без зависимости игры от браузера. useWorkspace владеет
навигацией и polling, api.ts — wire-контрактами, App.vue — представлением.
Логика агента, полномочия, RAG и ключи остаются на backend.

Слева отдельные диалоги, в центре сообщения и выбор модели, справа
live-контекст, индекс, источники выбранного хода и журнал MCP.
Live-контекст не заменяется снимком старого ответа при открытии истории.

Вопрос при неясном результате POST хранится как receipt с UUID:
повтор использует тот же ID, не создаёт второй платный вызов.
Смена чата не смешивает историю. Reload восстанавливает выбранный чат.
HTML модели и источников выводится как текст; источники не исполняются.

Тесты и сборка: npm ci; npm test; npm run build. Нужен Node >=22.12.
