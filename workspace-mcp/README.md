# Workspace MCP

Внутренний Kotlin MCP-сервер для чтения изолированных снимков игры
и сохранения Markdown-документов и patches отдельно от оригинала.

WorkspaceStore — единственный владелец volume workspace-data.
Исходный проект смонтирован read-only; его корень не выбирается моделью.
WorkspaceDataController создаёт снимки и экспортирует артефакты.
WorkspaceMcpConfiguration регистрирует пять инструментов SDK.

Перед сохранением сервер проверяет реальные чтения минимум трёх файлов.
Для замены документа нужны все исходные строки и правильный base_hash.
Произвольный shell, секреты, C#-запись и применение к игре отсутствуют.
