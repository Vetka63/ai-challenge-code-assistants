# Индексация и поиск

MarkdownChunker сохраняет исходные строки и заголовки. IndexService
получает snapshot через ProjectGateway, строит локальные embeddings,
атомарно публикует IndexRecord. Retriever делает exact cosine
и лексический RRF, возвращает источники, а не ответ.

Свежесть определяется Git SHA + fingerprint, а не одним dirty-флагом.
В /help устаревание означает предупреждение: поиск использует сохранённые
чанки и вектора READY индекса без обязательной переиндексации.
Смена digest/размерности требует переиндексации. Вектора лежат в SQLite,
не в Git. Генератор не участвует в построении индекса.
