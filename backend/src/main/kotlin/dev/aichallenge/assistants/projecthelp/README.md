# Помощник разработчика

ProjectHelpAgent инкапсулирует политики, историю, ProjectGateway, RAG
и Generator. Собственного произвольного файлового доступа у него нет.
HelpInputPolicy проверяет UUID/вопрос/провайдера. HelpOutputPolicy
проверяет только ID ссылок. DTO — models, алгоритм — service, правила — policy.

Вопрос сохраняется до запуска. Ошибка MCP, пустой ответ и restart не удаляют
его. Устаревший индекс не блокирует ответ: HelpTurn сохраняет indexContext
и предупреждение STALE_INDEX отдельно от ошибок. Модель получает текущий
Git-контекст и версию индексированных документов раздельно. Несовместимые
embeddings остаются блокирующей ошибкой. Алгоритм: docs/day31-architecture.md
в корне проекта.
