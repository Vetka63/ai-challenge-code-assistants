# AI Challenge Code Assistants

Отдельный проект ассистента разработчика для учебных дней 31–32.

## Текущее состояние

Подготовлен только Git-репозиторий и контекст проектирования. Backend,
frontend, RAG, MCP, модели и GitHub Action пока не реализованы.
Это не готовое приложение и не копия старого `ai-chat`.

## Проект-источник

[AI Challenge Game](https://github.com/Vetka63/ai-challenge-game) — отдельная
2D-игра на Unity/C#. Её README, docs и C# станут источниками для ассистента.
Игра не должна зависеть от доступности ассистента.

Локально проекты расположены рядом. Путь к игре будет явно настраиваться
на стороне ассистента; исходники игры не нужно копировать в этот репозиторий.

## Задания

- **День 31:** RAG по README/docs, read-only MCP с текущей Git-веткой игры,
  команда `/help` о структуре и правилах проекта.
- **День 32:** PR-пайплайн с diff, изменёнными файлами и RAG по документации
  и коду; текст ревью с багами, архитектурными проблемами и рекомендациями.

Подробнее: [контекст и границы](docs/project-context.md),
[связь репозиториев](docs/repository-link.md), [правила работы](AGENTS.md).

Предварительный стек — Kotlin/Spring Boot, Vue, локальные embeddings,
Ollama/DeepSeek и отдельный read-only MCP. Детали требуют согласования.

## Данные и безопасность

Секреты, локальные пути конфигурации, БД, индексы, веса и raw-результаты
не коммитятся. Публичность репозитория не означает публикацию runtime-данных
и не назначает лицензию исходникам автоматически.
