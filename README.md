# AI Challenge Code Assistants

Отдельное приложение ассистентов вокруг Unity-игры для учебных дней 31–34.

## Текущее состояние

Ветка дня 31: Kotlin/Spring Boot backend, Vue/TypeScript UI, SQLite,
локальные embeddings, read-only Project MCP и агент с командой /help.
Дни 32–34 остаются планом; PR Action, поддержка и запись файлов не включены.

## Проект-источник

[AI Challenge Game](https://github.com/Vetka63/ai-challenge-game) — отдельная
2D-игра на Unity/C#. Её README, docs и C# станут источниками для ассистента.
Игра не должна зависеть от доступности ассистента.

Локально проекты расположены рядом. Путь к игре будет явно настраиваться
на стороне ассистента; исходники игры не нужно копировать в этот репозиторий.

## Задания

- **День 31:** RAG по README/docs, read-only MCP с текущей Git-веткой игры,
  команда `/help` о структуре и правилах проекта.
- **День 32:** PR-пайплайн с diff, изменёнными файлами и RAG по документации
  и коду; текст ревью с багами, архитектурными проблемами и рекомендациями.

Согласованный [план дней 31–34](docs/roadmap-days-31-34.md),
[архитектура дня 31](docs/day31-architecture.md),
[запуск и сценарий для видео](docs/day31-guide.md).
Для продолжения начните с [контекста разработки](docs/assistant-handoff.md).
Подробнее: [контекст и границы](docs/project-context.md),
[связь репозиториев](docs/repository-link.md), [правила работы](AGENTS.md).

Стек: Java 21, Kotlin 2.2.21, Spring Boot 4.1.1, официальный MCP Java SDK
0.18.4 (клиент и сервер написаны на Kotlin), Vue 3.5.43, SQLite.

## Быстрый запуск

Из папки этого репозитория: docker compose up -d --build.
UI: http://localhost:8683, API: http://127.0.0.1:8682.
Перед первым запуском проверьте .env.example и внешний volume с весами.
Ключ DeepSeek задаётся только локально. По умолчанию без ключа доступна Ollama.

Игра монтируется только для чтения. Новые контейнеры, данные и порты отделены
от старого ai-chat. Не используйте down -v для остановки с сохранением истории.

## Данные и безопасность

Секреты, локальные пути конфигурации, БД, индексы, веса и raw-результаты
не коммитятся. Публичность репозитория не означает публикацию runtime-данных
и не назначает лицензию исходникам автоматически.
